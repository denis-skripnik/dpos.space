# dpos.space — итог исправлений аудита

## Статус

Локальные изменения кода по согласованному аудиту реализованы и проверены. По отдельному разрешению Дениса HTTP-защита от встраивания включена на production: CSP `frame-ancestors 'self'` и X-Frame-Options `SAMEORIGIN`, оба с `always`. Конфигурация сохранена в резервную копию, nginx -t и reload успешны; реальные ответы 200 и 404 проверены. По последующему разрешению Дениса публичный веб-код обновлён выборочно: 20 файлов, без git pull/reset/push и без затрагивания серверных данных. Все публичные SHA-256 совпали с проверенной локальной версией. Публичный APK не заменялся; ранее отправленный debug APK теперь загружает обновлённый интерфейс. Реальные транзакции не выполнялись.

Этот документ описывает текущий результат и заменяет промежуточные статусы в журнале `plan.md`.

## Проверка исходных 16 пунктов

1. **Хранение ключей и миграция — реализовано.** Зашифрованный vault, парольная защита и passkey PRF, проверяемая активация и сохранение исходных записей при ошибке. Проверена сохранность ключей всех шести сетей после миграции и повторной разблокировки, включая импортированный из Minter seed Decimal. Проверено, что повреждённая запись одной сети не приводит к удалению остальных.
2. **Сторонние скрипты и CSP — локальный код исправлен; серверная защита от встраивания включена.** Внешние переводчик/аналитика заменены локальным RU/EN в опубликованном коде. По отдельному разрешению добавлены HTTP-заголовки `Content-Security-Policy: frame-ancestors 'self'` и `X-Frame-Options: SAMEORIGIN` с `always`; ответы `/`, `/index.html` (200) и отсутствующей страницы (404) подтверждают оба заголовка. HSTS сохранён, HTML главной страницы не изменился. Резервная копия конфигурации: `/www/backup/dpos-framing-20260919-185346/nginx-before.conf`. Остальные vhost-конфигурации не изменены, временная задача удалена.
3. **Полномочия Android bridge — реализовано.** Проверки точного origin и главного frame, неподписанный preview, native consent, фиксированный Decimal chain ID. Есть автоматические проверки; физический WebView остаётся отдельной границей приёмки.
4. **Повторная отправка — исправлено.** Синхронная блокировка операции и неизменяемый снимок формы, регрессия конкурентных отправок.
5. **Backup VIZ invite batch — исправлено.** Отправка привязана к конкретной подтверждённой резервной копии; изменения входных данных отменяют подтверждение.
6. **Повреждение VIZ authorities — исправлено.** Валидация весов/порогов, сохранение невыбранных полномочий и metadata, повторная проверка состояния перед отправкой. Проверен настоящий vendored VIZ serializer без broadcast.
7. **Остановка и отмена — исправлено в коде.** Проверки отмены после ожиданий и перед отправкой, браузерные и Android-регрессии.
8. **Отзыв native-разрешений и удаление аккаунтов — исправлено.** Полная синхронизация состояния и отзыв automation grants без потери прочих настроек.
9. **Перекрытие Android worker после timeout — исправлено в коде.** Общая блокировка, токены отмены и ограниченное выполнение. Проверено автоматическими тестами, не физическим сетевым стресс-тестом.
10. **Ложное подтверждение и повтор истории — исправлено.** Устойчивые pending/unknown-состояния, исходная граница истории, монотонные курсоры; нет автоматического повтора неопределённой отправки.
11. **Нетранзакционный импорт backup — исправлено.** Полная предварительная валидация, проверка записей, зашифрованный журнал восстановления и восстановление после перезагрузки. Проверены quota, частичная запись, блокировка во время операции, точка commit и прерывание между вкладками.
12. **Decimal SDK и адаптер — исправлено.** Используется воспроизводимая браузерная EVM-сборка официального `dsc-js-sdk@2.1.1`. Контракты используемых методов проверены на реально поставляемой библиотеке с перехваченным транспортом: DEL/token send, делегирование и вывод stake, создание безрезервного токена, NFT delegation/withdrawal, обмен и permit. Сохранены ticker UI, индивидуальная точность токенов, идентичность кошелька и проверка checksum. Нулевой minimum receive разрешён, но нулевой send не разрешается.
13. **Единицы энергии — исправлено.** RPC/native значения трактуются как basis points, UI — проценты; настройки мигрируют один раз, неизвестная энергия не разрешает голосование.
14. **Устаревшие API/APK из Service Worker — исправлено.** Финансовые API и latest APK загружаются только из сети с обходом HTTP-кэша; офлайн оболочка сохраняется.
15. **Курсоры уведомлений Minter/Decimal — исправлено.** Используются устойчивые идентификаторы транзакций, тихая миграция старых курсоров и проверка атомарности состояния.
16. **Секреты в диагностике — исправлено.** Общая очистка применяется к основным и дополнительным сообщениям ошибок, clipboard/rewards/частичным API-ответам и native bridge. Проверены WIF, BIP39, JSON credentials и отсутствие блокировки обычного текста. Преднамеренный экспорт ключей не изменён.

## Дополнительные согласованные дефекты

- Ввод денежных сумм: исправлены HTML-проверки и реальные callbacks подготовки операций. Проверены 0, 10, 100, дроби с точкой/запятой и отказ для отрицательных/нечисловых значений. Охвачены Minter swap/liquidity/hub, Decimal minimum receive и аналогичная проверка суммы создания аккаунта Golos.
- VIZ custom ID: валидация 1–32 символов; исправлена совместимость HTML pattern с Unicode Sets (`v`) современных браузеров.
- Полный сброс VIZ-ключей: четыре публичных ключа проверяются настоящим SDK; metadata сохраняется точно, включая пустую строку; unreadable metadata не заменяется пустым объектом. Перед отправкой повторно проверяются аккаунт, authorities, memo и metadata.
- Явный пустой список уведомлений означает «ничего», а не «все операции».
- Устаревшие результаты асинхронных маршрутов не перерисовывают новую страницу в проверенных сценариях; исправлено зависание Minter Explorer.
- Read-only API имеют deadlines; поздние результаты notification scan не фиксируют состояние.
- Native seed import проверяет BIP39 и соответствие адреса, сохраняя прежнюю запись при отказе.
- Модальные окна проверены в Chromium: непрозрачный фон в обеих темах, Enter для открытия, фокус внутри, Escape и возврат фокуса.
- Добавлен локальный web runner и GitHub Actions workflow. Удалённый CI не запускался, поскольку push не выполнялся.
- Инвентаризация полноты лицензий всех исторических библиотек остаётся ранее согласованным исключением.

## Безопасность новой Decimal-сборки

В браузер экспортируется только замороженный namespace `Wallet`, `DecimalEVM`, `DecimalNetworks`, `verifyAddress`. Криптография и derivation выполняются ethers, а не самодельным алгоритмом; путь `m/44'/60'/0'/0/0` сохранён.

Граф сборки запрещает legacy Cosmos/ICS23/protobuf/Tendermint signing/native secp256k1/Web3/Swarm/request/tar. Проверены и успешная сборка, и отказ gate на запрещённых зависимостях. EVM-код операций берётся из upstream SDK.

Установочное дерево upstream npm по-прежнему содержит предупреждения безопасности. Это не равнозначно присутствию этих пакетов в браузерном артефакте: перечисленные legacy-модули исключены из его графа. Утверждения «всех уязвимостей нет» этот аудит не делает.

Поставляемый файл: `v3/vendor/decimal/decimal-sdk-web.js`.

- Размер: 743713 байт.
- SHA-256: `3eaf3ffaf198aa640457189e443b735c2af76d37ffeeafb10129a021ec6b25a0`.
- Повторный `npm test` в `tools/decimal-sdk` пересобрал идентичный файл и завершился успешно.
- Обновлены версии URL SDK, локальных ресурсов и Service Worker в опубликованной версии.
